Projects in this repository include / will be inclouding diffrent tehnologies, such as:

## 🚀 How to use
#### 1. Clone the repository
First, clone the repository to your local machine using Git. You can do this by running the following commend in your terminal:
```bash
git clone https://github.com/helloGrimm/web-portfolio.git
```
#### 2. Navigate to a specific project
Once you cloned the respository, navigate to the folder of the specific project you'd like to explore. Each projects is stored in its one folder within the repository.
